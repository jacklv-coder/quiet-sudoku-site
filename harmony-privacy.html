一刻数独 · 隐私政策

适用于鸿蒙版一刻数独 1.0.0。生效日期：2026 年 10 月 15 日。运营者：闾金涛（Jintao Lv）。

单机运行与本地数据

一刻数独是一款单机数独应用。无需注册或登录；解题、题库、分步提示、教学和练习均可离线使用。本版本不提供云同步或跨设备同步，不向开发者服务器上传解题数据，也没有广告、分析或跟踪 SDK。

棋盘、候选笔记、撤销记录、已完成题目、学习记录和设置保存在当前设备的应用存储中，用于保存和继续进度。应用不收集姓名、电话号码、通讯录、位置、照片或设备广告标识。

系统权限和可选操作

振动权限仅用于本机按键触感，可在应用设置关闭。可选每日提醒由系统本地安排；仅在你主动开启后请求通知许可，可在应用或系统通知设置关闭。应用使用后台代理提醒权限安排本地提醒，无需服务器推送。

只有你主动使用系统分享菜单、选择接收方后，所选完成记录才会交给该目标应用。目标应用如何处理信息由其隐私政策规定。应用不会自动分享。

保留、删除和备份

本地数据保留在当前设备，直到你删除相应存档或卸载应用。你可在存档页删除非当前棋盘；删除棋盘不会删除完成统计。卸载应用会移除本地应用数据，请谨慎操作。设备操作系统是否备份或恢复应用数据，取决于你自己的系统备份设置；这不是本应用提供的云同步。

支持与外部网站

“支持与帮助”由你主动打开外部浏览器访问支持网页。支持网页托管在 GitHub Pages，公开问题反馈使用 GitHub Issues；访问或联系支持需要联网，并受 GitHub 的隐私政策约束，不影响应用本身的离线功能。我们只使用你主动提供的内容处理支持请求。

GitHub Issues 是公开渠道，请勿提交密码、手机号、账号、身份证件或其他敏感个人信息。反馈时只需描述应用版本、设备型号及复现步骤。

未成年人和政策更新

本应用不设用户账号，也不建立个人资料。未成年人请在监护人指导下使用外部支持或分享功能。若未来版本改变数据处理方式，我们会相应更新政策，并在需要时征求你的同意。

联系与隐私权利

如对本政策或本地数据管理有疑问，可通过支持页面联系运营者。开发者没有你的本地棋盘副本，因此不能远程读取、导出或删除设备中的存档；上述操作请在自己的设备完成。
